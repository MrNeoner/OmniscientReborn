## 📋 О плагине

**Omniscient Reborn** — плагин для клиентов **Telegram** на платформе **Elyx**, предоставляющий **расширенные уведомления о сетевом статусе**, **прочтении сообщений**, **наборе текста** и **изменении профиля** для выбранных пользователей, а также детальную фиксацию сессий с построением **суточной инфографики активности**.

Все данные и журнал событий сохраняются **исключительно локально** на вашем устройстве в зашифрованном виде.

---

## 🔥 Ключевые возможности

* **📊 Высокоточная фиксация сессий:**
  Регистрация каждого входа и выхода контакта из сети с точностью до секунды. Автоматическое определение кратковременных «микро-сессий» (когда контакт зашёл и сразу вышел).
* **🎨 Экспорт инфографики:**
  Генерация визуальных аналитических карточек высокой чёткости с 24-часовым почасовым графиком распределения онлайна, пиковыми часами активности, счётчиком сессий и средней продолжительностью. Поддерживаются **светлая** и **тёмная** темы оформления, а также установка **собственного фона из галереи**.
* **🔔 Умные уведомления:**
  Гибкая настройка оповещений: всплывающие Bulletin внутри приложения, нативные системные уведомления Android и интеграция с модулем **HyperBridge**.
* **🛡️ Локальная безопасность и приватность:**
  База данных и история защищены шифрованием с привязкой к конкретному устройству. Никаких внешних серверов, телеметрии и утечек.
* **💾 Резервное копирование и экспорт данных:**
  Возможность в любой момент выгрузить историю активности в **CSV**, **TXT**, переслать текстовой сводкой или создать полный зашифрованный бэкап с автоматическим регулярным сохранением.
* **⚡ Встроенный загрузчик обновлений:**
  Проверка и установка актуальных версий плагина напрямую из официального репозитория **GitHub** в один тап.

## 🛠️ Сборка из исходников

Для самостоятельной сборки потребуется установленный `elyxbuilder` (`elyb`):

```bash
git clone https://github.com/MrNeoner/OmniscientReborn.git
cd OmniscientReborn
python build_all.py
```

Собранный плагин **`omniscient_reborn.eaf`** появится в корне проекта и в папке `builds/`.
